### What you get when you run

```bash
npx sunmeat
# or
npx sunmeat@latest
```

A beautiful, colorful, interactive CLI card featuring:

- Cool ASCII art banner  
- Quick bio & current status  
- Skills with progress bars  
- Tech stack (languages, frameworks, tools)  
- Hobbies & passions with icons  
- Random inspiring quote  
- Contact links + auto-opens website in browser  
- **Matrix rain mode** (yes, real digital rain) 🌧️

### Features

- Clean & modern terminal UI  
- Keyboard navigation (1–6 + 0)  
- Animated typing effects  
- Custom color theme  
- Fullscreen Matrix screensaver with exit on Enter  
- Cross-platform (Windows, macOS, Linux)

### Quick Start

Just run once:

```bash
npx sunmeat
```

Want it even faster? Add an alias:

```bash
# In ~/.zshrc or ~/.bashrc
alias alex='npx sunmeat'
```

Now just type `alex` anytime.

3. Update `package.json` → change `name`, `version`, `bin`  
4. `npm publish` under your own scope or name  
5. Enjoy: `npx your-username`
